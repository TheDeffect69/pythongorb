# Распределённая лаборатория загрузки видео

Координатор выдаёт агентам арендуемые блоки ID, хранит результаты в SQLite и показывает прогресс в веб-панели. Для демонстрации используется локальный управляемый HTTP-источник с тестовыми файлами. Работа стенда не требует учётной записи видеосервиса, доступа в интернет или внешних пакетов Python.

## Быстрый запуск

Требуется Python 3.11 или новее. Из корневого каталога проекта выполните команду:

```console
python demo.py
```

Откройте **http://127.0.0.1:8090**. Введите значение поля `operator` из файла `.lab/credentials.json`. Для администрирования узлов используйте значение `admin`. Файл создаётся при первом запуске. Ограничьте доступ к нему своей учётной записью, особенно при размещении проекта в общем каталоге Windows.

Дождитесь регистрации трёх узлов. Создайте задание для `[0,59]`, укажите размер блока 5, общий лимит 20 запросов/с и запустите задание. Небольшие блоки позволят увидеть работу всех трёх агентов даже на этом коротком диапазоне. В профиле демонстрации ID 1 даёт запрет доступа, ID 2 сначала отвечает 429, ID 3 — 500, ID 4 запрещает скачивание, ID 5 возвращает 404, а у ID 6 и 7 обрывается первая загрузка. У ID 7 отключена поддержка Range.

В каталоге `.lab` находятся ключи локального стенда, база данных и три отдельных каталога файлов. Ctrl+C завершает процессы. Повторный запуск с тем же каталогом использует прежнюю базу и ключи. Для отдельного опыта задайте `python demo.py --state .lab/second --port 8190 --mock-port 8191`. Локальный профиль имитирует три сервера тремя независимыми процессами на одном компьютере.

## Данные тестового источника

`mock_service.py --config fixtures/demo.json` задаёт ответы по ID. Поля `media_statuses` и `files_statuses` перечисляют последовательность статусов для маршрута, последний статус повторяется. Настройки `retry_after`, `delay_ms`, `size`, `download_allowed`, `allow_range` и `interrupt_downloads` управляют задержками, размером и поведением загрузки. `missing_every` задаёт частоту пропусков для ID без индивидуального профиля. Маршрут `GET /stats` показывает текущий и максимальный фактический параллелизм HTTP-операций и счётчики ответов.

Файлы mock-профиля содержат детерминированные тестовые байты с контрольной суммой SHA-256. Они предназначены для проверки транспорта и целостности.

## Собственные видео

Для демонстрации с настоящими видео можно передать каталог разрешённых материалов: `python demo.py --catalog media/catalog.json --state .lab/catalog`. Разместите JSON и файлы, на которые он ссылается, в одном дереве каталогов. Пример записи:

```json
{
  "12": {"title": "Запись семинара", "file": "seminar.mp4", "mime_type": "video/mp4", "download_allowed": true},
  "15": {"title": "Только метаданные", "download_allowed": false}
}
```

В этом режиме агент получает оригинальные байты файла, локальный источник поддерживает HTTP Range, а в метаданных сохраняется ссылка на страницу вида `https://kinescope.io/12`. Числовое соответствие и разрешение задаёт владелец каталога. Неизвестный ID возвращает 404. Стенд не устанавливает соединений с Kinescope и не проверяет доступность реальных страниц на платформе.
