## Границы стенда

- Агенты в нагрузочном отчёте работали отдельными процессами на одном компьютере. Влияние WAN и независимых физических дисков измеряют при развёртывании на разных хостах.
- Испытания используют управляемый источник и отдельно проверяют каталог файлов владельца. Интеграция с действующим внешним видеосервисом потребует подтверждённого способа доступа и проверки на разрешённых материалах.
- Запись результата в SQLite и атомарное переименование файла на другом узле не образуют единую транзакцию. При аварии между ними может остаться физический файл без подтверждённой записи. Подробности приведены в [описании архитектуры](architecture.md).
- Обновление агента через systemd предполагает подготовленный администратором релиз и настроенные права. Полную активацию и откат на реальном узле следует включить в проверку инфраструктуры.
- Для расширенных характеристик Linux агент использует procfs. Некоторые системные счётчики Windows отличаются. В открытой вкладке оператора период опроса равен трём секундам, к нему прибавляется задержка сети.
- В БД сохраняются результаты ID и попытки обработки блока. Временные состояния активных проверок и скачиваний передаются через heartbeat. Полной долговременной истории каждого промежуточного статуса и каждого HTTP-повтора по одному файлу в этом варианте нет.
