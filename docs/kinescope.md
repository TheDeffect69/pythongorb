# Подключение Kinescope

Агент запрашивает метаданные видео из рабочего пространства через авторизованный `GET /v1/videos/{video_id}`, проверяет страницу из `play_link` и при наличии `assets[].download_link` скачивает файл. В документации встречаются числовые и буквенно-цифровые ссылки плеера. API ID может отличаться от номера в ссылке. [Справочник Video API](https://docs.kinescope.ru/api/video/core/)

## Запуск

1. Передайте `LAB_KINESCOPE_TOKEN` в окружение из менеджера секретов. Для демонстрации нужны права чтения собственного проекта и доступа к выбранному материалу. [Авторизация и область действия токена](https://docs.kinescope.ru/instrukcii-dlya-razrabotchikov/api-obshchie-pravila/)
2. Выполните `python kinescope_index.py --project PROJECT_ID --output .lab/kinescope.json`. Утилита обходит страницы списка видео выбранного проекта, сохраняет соответствия числовых ссылок плеера и API ID и выводит число видео со ссылками другого формата.
3. Для буквенно-цифровой ссылки можно назначить локальный номер. Формат записи — `{"27":"API_ID_ВАШЕГО_ВИДЕО"}`. Агент получает фактический адрес страницы из ответа API.
4. Запустите `python demo.py --kinescope-index .lab/kinescope.json --state .lab/live`. Через панель или `python jobctl.py submit --from A --to B` задайте диапазон, содержащий известный номер. Для запуска CLI передайте токен оператора текущего координатора. Удалённому агенту задайте `--source kinescope --kinescope-index PATH`, токен и тот же индекс.
5. На защите сопоставьте URL страницы, статус ID, размер файла и SHA-256 в метаданных. Нагрузку, ответы 429, 500 и аварийный обрыв воспроизводите на локальном источнике.

## Разрешения и целостность

Число вне подготовленного индекса получает `skipped` с причиной `outside_workspace_index`. Ответ 404 от платформы соответствует `not_found`, а 401 и 403 — `forbidden`. Отсутствие ссылки скачивания оставляет метаданные и статус `skipped`. Агент использует HTTPS-хосты Kinescope и его CDN. Перенаправления отклоняются. Токен передаётся только на `api.kinescope.io`, параметры подписанного URL остаются в памяти агента.

Если API передаёт MD5 файла, агент сверяет его и размер до публикации, затем сохраняет SHA-256. При отсутствии контрольной суммы источника агент начинает передачу с начала, вычисляет SHA-256 потока и сверяет с временным файлом. Это подтверждает локальную запись и размер. Возможность скачать конкретный оригинал определяется правами рабочего пространства и актуальным ответом API.

Контрактные тесты используют ответы формата официального API. Сквозная проверка с аккаунтом владельца требует его токена и разрешённого видео.
